
# Simple Interest Calculator

## Project Overview
This project calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Rate of interest
- Time period

## Technology
- Bash scripting
- Git and GitHub

## Usage
Run the `simple-interest.sh` script in a Bash terminal and enter the requested values.
